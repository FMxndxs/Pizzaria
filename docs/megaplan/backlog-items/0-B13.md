# 0-B13: Convenção e README de migrations

## Business Outcome
Qualquer desenvolvedor (ou agente) sabe exatamente em que ordem aplicar as migrations do projeto, evitando erros de sequência ou execuções duplicadas.

## Scope
- Cria `docs/database/migrations/README.md` com:
  - Convenção de nomeação (`NNN_descricao.sql`).
  - Ordem de aplicação de todas as migrations (001 a 006 + futuras).
  - Instrução sobre o statement isolado de `ADD VALUE 'ready'` (0-B1).
  - Como executar: SQL Editor do Supabase (não há CLI configurada).
  - Instrução de atualizar `schema.sql` sempre que uma migration for aplicada.
- **Não inclui:** as migrations em si (cada uma já tem seu B-item); automação de aplicação.

## Dependencies
- 0-B1 a 0-B9 (todos os arquivos de migration de Cycle 0 já escritos, para documentar a ordem correta)
