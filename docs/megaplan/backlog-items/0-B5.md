# 0-B5: Coluna + gerador de número de pedido

## Business Outcome
Cada pedido recebe automaticamente um código curto amigável (ex.: `#A4F9`) no momento da inserção, gerado no banco via sequence + base32 Crockford.

## Scope
- Cria `CREATE SEQUENCE IF NOT EXISTS order_code_seq START 1`.
- Cria função `gen_order_code(n bigint)` — base32 Crockford (alfabeto sem I/L/O/U), mínimo 4 chars, cresce naturalmente após ~1M pedidos (**nunca truncar**).
- Adiciona coluna `orders.order_code text NULL` e `orders.order_seq bigint NULL`.
- Cria trigger `BEFORE INSERT ON orders` → popula `order_seq` (nextval) e `order_code` (gen_order_code(order_seq)).
- Atualiza `docs/database/migrations/002_orders_extend.sql` (arquivo iniciado em 0-B1).
- **Não inclui:** backfill de pedidos existentes (→ 0-B6); coluna `updated_at` e `fulfillment_type` (também em `002`, mas outros B-items).

## Dependencies
- Nenhuma (independente do enum e da tabela de histórico).

## Implementation Notes
Geração no banco (não no service layer) garante que toda via de inserção — Server Actions hoje, REST depois, SQL direto — produz o mesmo formato. Sequence é à prova de concorrência e não produz gaps problemáticos.

O alfabeto Crockford base32: `0123456789ABCDEFGHJKMNPQRSTVWXYZ` (sem I, L, O, U para evitar confusão visual). Mínimo 4 chars = `0000` a `ZZZZ` = até 1.048.576 pedidos antes de crescer para 5 chars.
