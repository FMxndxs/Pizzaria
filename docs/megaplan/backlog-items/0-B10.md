## Implementation Notes
O padrão de injeção de `SupabaseClient` é o seam que cumpre ADR-002: Server Actions passam o `createServerClient()` (cookie-based); futuros route handlers passam um client com token Bearer. A lógica de negócio não sabe qual é qual.

Correção do bug de `flavor.type`: `clientQueries.ts:54-57` monta `{ name, price }` mas ignora `type`. O `PizzaCartItem` tem `type` no nível do item (não do flavor), então `cartItemsToOrderItems` deve copiar `item.type` para cada flavor snapshot.
