## O que este guia cobre

Como copiar este sistema para um novo estabelecimento (nova pizzaria), do zero até um deploy funcional com o primeiro usuário owner cadastrado.

**Pré-requisitos:** conta Supabase, conta Vercel (ou outro host Next.js), domínio (opcional), número de WhatsApp do estabelecimento.
